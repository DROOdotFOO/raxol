# Tool / Action Catalog

Every built-in LLM-callable Agent Action, with its parameters and whether
it is sensitive.
Generated by `mix raxol.docs.tools` (run from `packages/raxol_payments`),
introspected from each action's `__action_meta__/0`. Do not edit by hand.
`mix raxol.docs.tools --check` fails when this file is stale.

Total: 19 tools, 7 sensitive.

## Authorization

A tool not marked sensitive runs. A tool marked **sensitive** is denied
(`Raxol.Agent.ToolPolicy.deny_sensitive/0`) unless the context of the call
carries a `:tool_authorizer`, which then decides every call. Over ACP the
agent is handed an authorizer that asks the editor once for each sensitive
call. `Raxol.Agent.Authorization` is a separate
[allow/ask/deny policy reducer](../features/AGENT_FRAMEWORK.md#authorization-allowaskdeny)
that a host can wire in; no tool-call path consults it by default.
