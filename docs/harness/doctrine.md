## 1. The soul

**Raxol is a machine that cannot lie to the one flying it.** One law at every
scale: *what is shown must be a provable projection of what is, and the wrong
thing must be unrepresentable.* Applied to pixels: every rendered value traces
to journal/model state; prominence is granted by a solver, never claimed;
motion is clocked by events, never by wall time.

The identity position — unclaimed by any shipped agent (LANDSCAPE §2) — is the
**evidential instrument**: an instrument panel grown around a log. Claude Code
is the literate houseguest, aider the austere craftsman, Grok Build the
theatrical cockpit; Raxol is the one whose aesthetic *is* epistemic honesty.
The target feeling: dense at the rim, quiet at the center, one thing glowing,
and complete certainty that if the panel shows nothing, nothing is wrong.
Costume vs body: themes/palettes are costume and welcome; the role graph, the
clocking law, and the zone registers are body and invariant.

**The one-line product thesis (north star): an instrument panel grown around a
log — never a replacement for the log.** Lineage: *fish, not htop* — enrich
the line the user is on; depth summoned, silence default; no inhabitation.

## 2. The two pillars

1. **Solved attention (the H-K economy).** Components declare a semantic role
   and a salience *request*; the Helmholtz-Kohlrausch solver assigns prominence
   against the user's actual ground. One certified-bright anchor per screen,
   zero-sum. Hand-set brightness or raw hex in a component is a defect
   (falsifier class 3). Guest, not occupier: never paint the user's background;
   the brand is a temperature threaded through roles, not a skin.
2. **Minimal-but-deep (the grown cockpit).** Start as a charged minimum (bare
   prompt carrying full identity); instruments accrete because work exists,
   never because we want to show them; persistence is earned
   (session/project/global pinning — policy OPEN, `adaptive/` is the candidate
   engine). Generative composition + solved attention is the pairing nobody
   else has: dynamically grown UI is only coherent because the solver, not a
   human hand, balances the screen.

## 3. The three operator moments

Everything optimizes three moments; anything serving none of them is suspect:

1. **Watching** — glanceable truth: what is it doing now (stage, not spinner),
   what has it consumed (context %, cost, live), what does it need from me.
   Working-vs-hung distinguishable at sight.
2. **Deciding** — review at the decision moment: the approval arrives with the
   diff there, expandable, scroll alive, blast radius stated. (93% of
   illegible prompts get blind-approved — the ones that remain must be
   maximally legible.)
3. **Returning** — catch-up as evidence: unread divider, restoration diff
   (turns elapsed, files touched, cost delta) — never a success toast.

## 4. Zone ontology: the log and the rim

Two zones, two ontologies, two registers — the split IS the visual language:

| | **Log** (center) | **Rim** (edges/overlays) |
|---|---|---|
| Ontology | History; projection of the journal | Present; projection of live state |
| Register | Zen-literate: markdown, prose-shaped, chromeless | Diegetic retrofuturism: readouts, meters, framed |
| Motion | Never animates; append-only; never repainted | The only zone that breathes |
| Lifecycle | Permanent facts with receipts | Ephemeral; dies into the log on settle |
| Author | The substrate (built, trusted chrome) | Grown (runtime-composed instruments) |

The register split is a **provenance channel**: minimal register = the
machine's body speaking; retrofuturist register = a grown instrument speaking.
Never bleed registers across zones (falsifier class 4).

*Post-substrate-pivot note (2026-07-18):* "never repainted" is a **logical**
law about content, not a byte law — see `architecture.md` §6. Sealed blocks
remain immutable as content; the full-viewport substrate may repaint the
screen from the model. Register discipline, clocking, and honesty rules are
unaffected by the pivot.

## 5. The clocking law (motion)

**Everything is clocked by the journal, not by wall time.**

- Motion exists only while events flow; spinners/meters tick on event arrival.
  Events stop → screen still. "Panel shows nothing → nothing is happening" is
  a property of the render loop, not a promise.
- Moving = in-flight claim (dim/italic); still = settled fact. The freeze to
  full weight is the commit beat.
- The completion blink: one event-driven flash on a tracked completion, then
  the widget dies into the log as a fact line with its receipt. No lingering.
- Tempo may encode state only because tempo derives from real event rate.
  Easing/decorative transitions: none — instant snap reads as native.
- Effect legality rule: any flourish is legal iff driven by a real event in
  the stream, illegal on a timer. One rule sorts every future flourish.

## 6. Channel grammar

- **Color:** achromatic chassis; chroma = signal; color encodes *state, never
  speaker*; the error hue is withheld from the resting UI (the alarm works
  because the room is silent); roles resolved through the theme, never raw hex.
  Default accent hue: **OPEN, V's call.**
- **Borders/shape:** log — no boxes, nesting via dot-and-hang; rim —
  single-line recessive bezels, titles inlaid in the border, heavy `┃` rails
  for ownership/selection; border color may carry focus/status, border shape
  never varies decoratively.
- **Typography:** four channels, one meaning each — **bold** = structure,
  **dim** = supporting/provisional, **italic** = in-flight, **reverse** = the
  one selected thing. Dim ramp is the opacity substitute. lowercase for
  identity/status verbs; UPPERCASE only for rim instrument labels.
- **Evidence surfaces:** "done" carries its receipt inline (exit code, diff
  stat, duration, tokens/cost, journal offset). The waiting state is
  evidential: named actual phase + live meter (`running mix test · 12s ·
  3.1k tokens`), never a whimsical gerund, never naked stillness. Glass
  walls: instruments can reveal their wiring.
- **Voice:** terse, factual, lowercase-calm; warmth from precision; errors =
  sober diagnostic + evidence + what the machine already did about it.
  Ceremony is legal only when it is evidence (the boot beat is a real POST).
- **Sound:** one semantic completion event, per-surface quiet idiom, two-note
  language at most ("done" / "needs you"), journal-fired, silent by default.

## 7. V-ratified rendering rulings (2026-07-17/18 — settled, never re-litigate)

1. **Speaker separation = mirrored outer-contour chevrons.** User `❯` at
   column 0 (touching the border), assistant `❮` at the same outer position;
   all dialogue content at the uniform 2-cell indent; both sigils bold, zero
   color; ASCII fallback `>`/`<`; the composer's live `❯` shares the sigil
   constant so echo and prompt can never drift; machinery blocks (tool/system
   glyph headers) keep the plain margin — dialogue is marked at the contour,
   machinery stays inside the frame. *Supersedes:* the `[assistant]`/`[user]`
   role tagline (mechanistic, role-colored — violated color-never-speaker) and
   the original Option A ("assistant = bare unmarked prose") which V amended
   same-day to the mirrored pair. Full option analysis:
   `../proposals/in-flight/harness-speaker-separation.md`.
2. **No role taglines; color never encodes speaker.** Authorship is carried by
   rails/glyphs/position; the hue budget stays with state.
3. **Boot = in-flow intro.** A "welcome back, operator" line above the chevron,
   erased at first seal; the full POST self-check card only under `--debug`.
   *Supersedes:* centered greeting; em-dash boot placeholders (violates
   charged-minimum).
4. **Tool render = one low-prominence line updated in place**
   (`⚙ name (args) · ✓ receipt · duration`), NO separate Tool Result block,
   foldable to full body. Reasoning collapses to one dim `∴` line, peekable.
5. **Glyphs: NO emoji, ever** ("it's gundam, not twitter") — monochrome
   text-presentation only; FE0E variant selector on dual-presentation
   codepoints (e.g. U+26A0); allowlist tripwire test. Braille spinner
   (`⠋⠙⠹…`) animates in the col-0 margin cell of a RUNNING tool line, riding
   existing tick machinery (never a new timer), dim, replaced by final state.
6. **^C is always double-press** (node semantics); `q`-on-empty single-press.
7. **Input pinned at screen bottom always** (chat semantics; scroll-entry
   seals). *Supersedes:* the earlier footer-follows-content ruling, which was
   an inline-substrate posture and is **shelved with the substrate** (see
   `architecture.md` §6).
8. **Fresh session per launch is the default forever** — resuming is always
   explicit opt-in (`--resume`/`--continue`/picker), never automatic. Binds
   the ACP durable-sessions bridge (`session/load`) and T13b-reattach.

## 8. What it is NOT

Not an app you inhabit (no alt-screen jail *as identity* — the 2026-07-18
substrate pivot makes full-viewport the rendering default, but the
inhabitation prohibitions on IDE cosplay, file trees, editors stand). Not
decorated: no motion that doesn't encode state change. Not a firehose: tool
output folds, probe chatter stays in an advisory side-channel. Not a nag. Not
a liar: no spinner-forever, no success toasts, no "done" without evidence. Not
a metrics wall: the slot belongs to the work.

## 9. The isomorphism underneath

The cohort builds TUIs that **perform activity**; this harness **discloses
state**. It is the journal's economic law surfacing at the pixel layer: *write
lavishly, inject selectively* becomes **know everything, show what matters**.
The salience system is the injection discipline made visual; the block model
is the journal made navigable; the strip is the materialized view made
glanceable. One system, not three features — the same shape as the backend's
one event-sourced system.

## 10. Falsifier classes (review checks — joined to the PR gauntlet, item 8)

1. **Unbound pixel** — a rendered value not traceable to journal/model state.
2. **Timer-clocked motion** — animation driven by wall time instead of events.
3. **Claimed prominence** — hand-set brightness/salience bypassing the H-K
   solver; raw hex in a component instead of a role token.
4. **Register bleed** — rim idiom in the log (history animating/repainting as
   content) or log idiom broken on the rim.
5. **Performed activity** — spinner/meter asserting work with no evidence
   surface attached.
6. **Unearned ceremony** — decorative boot/exit/transition beats not backed by
   a real check or event.
7. **(v2) Label-vs-binding divergence** — affordance text inconsistent with
   its declared call.

Meta-falsifier: cargo-culting the evidence look while faking the wiring loses
everything at once — a meter not wired to real numbers collapses the register
to theater, the one defect class the brand cannot survive.
